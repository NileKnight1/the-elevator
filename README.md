# The Elevator

# Gameplay
 There are 3 modes in the game, each on has a tutorial inside, a quick view:
 - Story mode: you should collect car parts to escape the place.
 - Floors Mode: you have to observe whether floor is usual or not, and the game loops till you win.
 - Fix Mode: you observe anomalies and FIX them yourself.

# Controls
- A-D moving
- Space - Jump
- Shift - Sprint

# Devices
- Supports touch and non touch devices
